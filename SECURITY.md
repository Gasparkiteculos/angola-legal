# Security policy

This repository is primarily documentation, metadata, and validation tooling.

## Reporting

Do not publish exploitable vulnerabilities or sensitive personal data in a public issue. Contact the repository maintainers privately through GitHub's security advisory reporting feature, if enabled. If it is unavailable, contact the repository owner through their verified GitHub profile and include only the minimum information needed.

## Scope

Report vulnerabilities in code, workflows, or handling of contributed data. For legal accuracy, rights, or privacy concerns, open a private report where possible and identify the affected path or record without republishing sensitive content.

We will acknowledge reports as soon as practical, investigate, and coordinate a fix or removal. No response-time guarantee is made at this initial stage.
